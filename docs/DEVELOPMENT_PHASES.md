# Development Phases

## Phase 1: Foundation (Current)
- Initialize project structure (frontend and backend).
- Create documentation.
- Establish database, realtime, linting, and testing configs.
- Create minimal health-check path.
- Verify end-to-end communication and local environment setup.

## Phase 2: Authentication & Users
- User registration, login, logout.
- JWT/Session management.

## Phase 3: Teams & Invitations
- Team CRUD.
- Invitations workflow.

## Phase 4: Conversations & REST Messaging
- Create conversations, manage participants.
- Send and retrieve messages via REST API.

## Phase 5: Realtime & AI Integration
- WebSockets for presence and typing indicators.
- Real-time message delivery.
- LLM abstraction and streaming AI responses.
